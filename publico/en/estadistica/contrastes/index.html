    How a test works

    The null hypothesis $H_0$ is what is accepted as true as long as the data do not say otherwise (μ = 500 g, the machine is properly adjusted); the alternative $H_1$ is what you want to prove. A statistic is calculated that, if $H_0$ is true, follows a known distribution, and we check whether it takes a value that is too unusual.

    Critical region and p-value

    The critical region is the set of values of the statistic so unusual that, if $H_0$ were true, they would only occur with probability α. The p-value is the probability of obtaining a value as extreme as the one observed, or more. Both give the same decision: $H_0$ is rejected if the statistic falls in the critical region, or equivalently, if $p < α$.

    Which statistic is used

    $Z = {x̄ − μ_0}/{σ/√n}$   $T = {x̄ − μ_0}/{s/√n}$   $Z = {p̂ − p_0}/{√(p_0 (1 − p_0)/n)}$

    $χ^2 = {(n − 1) s^2}/{σ_0^2}$   $F = {s_1^2}/{s_2^2}$

    Type I and type II errors, power and sample size

    Rejecting $H_0$ when it is true is the type I error, and its probability is α. Not rejecting it when it is false is the type II error (β), and $1 − β$ is the power of the test: the probability of detecting a difference that exists. Lowering α makes rejection harder and raises β: that is why not rejecting $H_0$ does not prove it is true. If you enter the true value of the parameter, the tool calculates β and the power (with the non-central t when the statistic is a t) and the sample size needed for the power you want (0.8 is usually asked for).

    $1 − β = P(\text{reject } H_0 \mid \text{true value})$;   for the mean with known σ: $1 − β = Φ(−z_{α/2} + δ) + Φ(−z_{α/2} − δ)$, with $δ = {μ − μ_0}/{σ/√n}$

    Effect size

    The p-value depends on the sample size: with a lot of data a tiny difference comes out “significant”. Cohen's d, $d = {x̄ − μ_0}/s$ (or the difference between two means divided by the pooled deviation), measures how many standard deviations the result is off: 0.2 is a small effect, 0.5 medium and 0.8 large. For proportions Cohen's h is used, $h = 2 \arcsin √{p_1} − 2 \arcsin √{p_2}$, with the same thresholds.

    Normality and variances

    The t and the χ² assume normal data. With the list of data the tool warns using Shapiro-Wilk (the most powerful with little data; Jarque-Bera needs a lot) and draws the quantile-quantile plot. To know whether several variances are equal (before an ANOVA or a t with equal variances) use “Several variances”: Levene (with the median) is robust and Bartlett is more powerful only if the data are normal.

    Frequently asked questions

    How is a hypothesis test carried out?

    H₀ and H₁ are stated, the statistic is calculated, it is compared with the critical region (or the p-value with α) and a decision is made. For a mean with known σ, z = (x̄ − μ₀)/(σ/√n): with x̄ = 52, μ₀ = 50, σ = 10 and n = 100, z = 2 > 1.96, so H₀ is rejected at 5 % (p ≈ 0.046).

    What is the p-value and what errors can be made?

    It is the probability of obtaining a result equal to or more extreme than the observed one if H₀ is true; H₀ is rejected if p < α. The type I error (α) is rejecting a true H₀; the type II error (β), failing to reject a false H₀.
