Taylor series

    The Taylor polynomial

    Near a point a, a differentiable function resembles a polynomial that has at a the same value and the same derivatives as it. The one of degree n is the Taylor polynomial:

    $P_n(x) = f(a) + f′(a) (x − a) + {f″(a)}/{2!} (x − a)^2 + … + {f^{(n)}(a)}/{n!} (x − a)^n$

    The coefficient of $(x − a)^k$ is $c_k = {f^{(k)}(a)}/{k!}$. The degree-1 one is the tangent line, and each extra degree corrects the curvature a little better. When a = 0 it is called the Maclaurin polynomial.

    The error: Lagrange remainder

    When f(x) is replaced by $P_n(x)$ an error is made, the remainder $R_n(x) = f(x) − P_n(x)$. If f has an (n + 1)-th derivative between a and x, there is a ξ between the two with

    $R_n(x) = {f^{(n+1)}(ξ)}/{(n+1)!} (x − a)^{n+1}$

    We do not know the value of ξ, but if $|f^{(n+1)}| ≤ M$ on that interval, the error is at most $M |x − a|^{n+1}/(n+1)!$. To make the error smaller than a given amount, look for the smallest n that does so.

    Known Maclaurin expansions

    • $e^x = 1 + x + {x^2}/{2!} + {x^3}/{3!} + … = Σ_{k=0}^{∞} {x^k}/{k!}$, for all x
    • $sin x = x − {x^3}/{3!} + {x^5}/{5!} − … = Σ_{k=0}^{∞} {(−1)^k x^{2k+1}}/{(2k+1)!}$, for all x
    • $cos x = 1 − {x^2}/{2!} + {x^4}/{4!} − … = Σ_{k=0}^{∞} {(−1)^k x^{2k}}/{(2k)!}$, for all x
    • $ln (1 + x) = x − {x^2}/{2} + {x^3}/{3} − … = Σ_{k=1}^{∞} {(−1)^{k+1} x^k}/{k}$, for −1 < x ≤ 1
    • ${1}/{1 − x} = 1 + x + x^2 + x^3 + … = Σ_{k=0}^{∞} x^k$, for |x| < 1
    • $arctan x = x − {x^3}/{3} + {x^5}/{5} − … = Σ_{k=0}^{∞} {(−1)^k x^{2k+1}}/{2k+1}$, for |x| ≤ 1
    • $(1 + x)^α = 1 + α x + {α (α − 1)}/{2!} x^2 + … = Σ_{k=0}^{∞} binom(α, k) x^k$, for |x| < 1

    With them others are obtained without differentiating: replacing x by $−x^2$ in the one for $e^x$ gives $e^{−x^2} = 1 − x^2 + {x^4}/{2} − …$, and multiplying the one for sin x by x gives the one for x sin x.

    Radius of convergence

    The Taylor series $Σ c_k (x − a)^k$ converges for $|x − a| < R$ and does not converge for $|x − a| > R$. The radius is obtained with the ratio test, $R = lim_{k → ∞} {|c_k|}/{|c_{k+1}|}$, or with the root test, ${1}/{R} = lim sup |c_k|^{1/k}$, and it is the distance from a to the nearest point, possibly complex, where f stops being defined: for ${1}/{1 + x^2}$ at a = 0 it is R = 1, because of the points ±i, even though over the reals the function has no problems.

    Outside its interval of convergence the series does not approach the function no matter how high the degree: try it with ln(1 + x) and x₀ = 1.5. And adding these series with x = iθ gives Euler's formula, $e^{iθ} = cos θ + i sin θ$, which is used in Complex numbers.

    The calculator estimates R with 80 coefficients, searches the complex plane for the singularity that fixes it and studies the two endpoints, $x = a ± R$, where each series goes its own way: that of ln(1 + x) converges at x = 1 (alternating harmonic series) and diverges at x = −1 (harmonic series), so its interval of convergence is $(−1, 1]$. When at an endpoint the signs follow no pattern, it says so and leaves it to be studied separately.

    Removable singularities

    ${sen x}/{x}$ is not defined at 0 (it gives 0/0), but expanding the numerator, $sin x/x = (x − {x^3}/{6} + …)/x = 1 − {x^2}/{6} + …$, you can see it tends to 1. Giving it that value at 0 the function becomes differentiable and has a Taylor polynomial.

    Limits with Taylor

    For a 0/0 limit the numerator and denominator are replaced by their expansions and the first nonvanishing term of each is compared: if they start with the same power, the limit is the quotient of their coefficients; if the numerator starts higher, it is 0; and if the denominator starts higher, it goes to ±∞ (or does not exist if the one-sided limits have different signs). For example,

    $lím_{x → 0} {sen x − x}/{x^3} = lím_{x → 0} {−{x^3}/{6} + …}/{x^3} = −{1}/{6}$

    A limit at infinity is brought to 0 with the change $t = {1}/{x}$ (write inf or -inf in the point field): $lim_{x → ∞} x sin({1}/{x}) = lim_{t → 0} {sin t}/{t} = 1$. And a power with x in the exponent is written as $f^g = e^{g · ln f}$ and the limit of the exponent is computed: $lim_{x → ∞} (1 + {1}/{x})^x = e^{lim x · ln(1 + 1/x)} = e^1 = e$.

    Frequently asked questions

    How is the Taylor polynomial calculated?

    P(x) = Σ f⁽ⁿ⁾(a)/n!·(x − a)ⁿ, and Maclaurin if a = 0. For example, eˣ ≈ 1 + x + x²/2 + x³/6, sin x ≈ x − x³/6 and cos x ≈ 1 − x²/2 + x⁴/24. With degree 3, e^0.1 ≈ 1.105167 (the true value is 1.105171).

    How is the error bounded?

    With the Lagrange remainder, R_n = f⁽ⁿ⁺¹⁾(c)/(n + 1)!·(x − a)ⁿ⁺¹ for some c between a and x. With degree 2 for e^0.1: |R| ≤ e^0.1/3! · 0.1³ ≈ 1.8·10⁻⁴.
