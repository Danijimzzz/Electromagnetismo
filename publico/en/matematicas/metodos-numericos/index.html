    Roots of equations

    Almost no equation like $cos x = x$ can be solved for x, but you can get as close to the solution as you like. Bisection starts from an interval $[a, b]$ where $f$ changes sign and halves it again and again: it is slow, but it always works. Newton-Raphson follows the tangent, $x_{n+1} = x_n − f(x_n)/f′(x_n)$, and near the root it doubles the correct digits at each step, although it can run away if it starts far off or if $f′$ vanishes. The secant method does the same without differentiating, using the line through the last two points. Fixed point writes the equation as $x = g(x)$ and iterates $x_{n+1} = g(x_n)$; it converges if $|g′| < 1$ near the solution.

    Numerical integration

    For an integral with no antiderivative, like that of $e^{−x^2}$, $[a, b]$ is split into $n$ pieces of width $h$. The trapezoid rule joins the points with straight lines and has an error of order $h^2$; Simpson's rule passes parabolas through each three points, needs $n$ even and its error is of order $h^4$: with the same points, it is usually much more accurate.

    Differential equations

    For $y′ = f(x, y)$ with $y(x_0) = y_0$ we advance in steps of size $h$. Euler follows the tangent, $y_{n+1} = y_n + h f(x_n, y_n)$, and its error is proportional to $h$. Heun averages the slope at the start and at the end of the step (error of order $h^2$), and Runge-Kutta 4 combines four slopes (error of order $h^4$): it is the one almost all programs use.

    Frequently asked questions

    How do you find a root with bisection or Newton-Raphson?

    Bisection: with f(a)·f(b) < 0 take the midpoint and keep the half where the sign changes, and the error halves at each step. Newton: xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ). For x² − 2 = 0 with x₀ = 1.5, x₁ = 1.5 − 0.25/3 ≈ 1.4167 (√2 = 1.4142).

    How do you integrate with trapezoids or Simpson?

    Trapezoids: (h/2)[f₀ + 2Σfᵢ + fₙ]; Simpson: (h/3)[f₀ + 4(odd) + 2(even) + fₙ]. For ∫₀¹ x² dx with Simpson and n = 2, (0.5/3)(0 + 4·0.25 + 1) = 1/3, which is exact.
