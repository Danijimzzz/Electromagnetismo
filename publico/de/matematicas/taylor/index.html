Taylor-Reihen

Berechne das Taylor-Polynom (oder Maclaurin-Polynom) einer Funktion an einer Stelle mit ihren Ableitungen und Koeffizienten, nutze es zur Näherung eines Werts und schätze den Fehler mit dem Lagrange-Restglied ab. Das Diagramm zeigt, wie sich jeder Grad der Funktion weiter annähert.

Daten

Schreibe die Funktion mit x: e^x, sin x, cos(2x), ln(1+x), √x, arctan x, 1/(1−x), x^3 − 2x… Die Stelle kann π enthalten: π/6. Unter „Grenzwert mit Taylor“ schreibe einen Quotienten: (sin x − x)/x^3.

Herleitung

    Werbung

    Das Taylor-Polynom

    In der Nähe einer Stelle a ähnelt eine differenzierbare Funktion einem Polynom, das in a denselben Wert und dieselben Ableitungen hat wie sie. Das vom Grad n ist das Taylor-Polynom:

    $P_n(x) = f(a) + f′(a) (x − a) + {f″(a)}/{2!} (x − a)^2 + … + {f^{(n)}(a)}/{n!} (x − a)^n$

    Der Koeffizient von $(x − a)^k$ ist $c_k = {f^{(k)}(a)}/{k!}$. Das vom Grad 1 ist die Tangente, und jeder weitere Grad korrigiert die Krümmung etwas besser. Für a = 0 heißt es Maclaurin-Polynom.

    Der Fehler: Lagrange-Restglied

    Ersetzt man f(x) durch $P_n(x)$, macht man einen Fehler, das Restglied $R_n(x) = f(x) − P_n(x)$. Hat f zwischen a und x die Ableitung n + 1, gibt es ein ξ zwischen beiden mit

    $R_n(x) = {f^{(n+1)}(ξ)}/{(n+1)!} (x − a)^{n+1}$

    Man weiß nicht, wie groß ξ ist, aber wenn $|f^{(n+1)}| ≤ M$ in diesem Intervall, ist der Fehler höchstens $M |x − a|^{n+1}/(n+1)!$. Damit der Fehler kleiner als eine vorgegebene Größe ist, sucht man das kleinste n, das dies erfüllt.

    Werbung

    Bekannte Maclaurin-Entwicklungen

    • $e^x = 1 + x + {x^2}/{2!} + {x^3}/{3!} + … = Σ_{k=0}^{∞} {x^k}/{k!}$, für alle x
    • $sin x = x − {x^3}/{3!} + {x^5}/{5!} − … = Σ_{k=0}^{∞} {(−1)^k x^{2k+1}}/{(2k+1)!}$, für alle x
    • $cos x = 1 − {x^2}/{2!} + {x^4}/{4!} − … = Σ_{k=0}^{∞} {(−1)^k x^{2k}}/{(2k)!}$, für alle x
    • $ln (1 + x) = x − {x^2}/{2} + {x^3}/{3} − … = Σ_{k=1}^{∞} {(−1)^{k+1} x^k}/{k}$, für −1 < x ≤ 1
    • ${1}/{1 − x} = 1 + x + x^2 + x^3 + … = Σ_{k=0}^{∞} x^k$, für |x| < 1
    • $arctan x = x − {x^3}/{3} + {x^5}/{5} − … = Σ_{k=0}^{∞} {(−1)^k x^{2k+1}}/{2k+1}$, für |x| ≤ 1
    • $(1 + x)^α = 1 + α x + {α (α − 1)}/{2!} x^2 + … = Σ_{k=0}^{∞} binom(α, k) x^k$, für |x| < 1

    Mit ihnen erhält man weitere ohne Ableiten: Ersetzt man in der von $e^x$ x durch $−x^2$, ergibt sich $e^{−x^2} = 1 − x^2 + {x^4}/{2} − …$, und multipliziert man die von sin x mit x, ergibt sich die von x sin x.

    Konvergenzradius

    Die Taylor-Reihe $Σ c_k (x − a)^k$ konvergiert für $|x − a| < R$ und konvergiert nicht für $|x − a| > R$. Der Radius ergibt sich mit dem Quotientenkriterium, $R = lim_{k → ∞} {|c_k|}/{|c_{k+1}|}$, oder dem Wurzelkriterium, ${1}/{R} = lim sup |c_k|^{1/k}$, und ist der Abstand von a zum nächsten Punkt, auch komplex, an dem f nicht mehr definiert ist: Für ${1}/{1 + x^2}$ bei a = 0 ist R = 1, wegen der Punkte ±i, obwohl die Funktion in den reellen Zahlen keine Probleme hat.

    Außerhalb ihres Konvergenzintervalls nähert sich die Reihe der Funktion nicht an, wie hoch der Grad auch steigt: Probiere es mit ln(1 + x) und x₀ = 1,5. Und summiert man diese Reihen mit x = iθ, ergibt sich die Eulersche Formel, $e^{iθ} = cos θ + i sin θ$, die in Komplexe Zahlen verwendet wird.

    Der Rechner schätzt R mit 80 Koeffizienten, sucht in der komplexen Ebene die Singularität, die ihn festlegt, und untersucht die beiden Ränder, $x = a ± R$, wo jede Reihe eigene Wege geht: Die von ln(1 + x) konvergiert bei x = 1 (alternierende harmonische Reihe) und divergiert bei x = −1 (harmonische Reihe), ihr Konvergenzintervall ist also $(−1, 1]$. Folgen an einem Rand die Vorzeichen keinem Muster, sagt er es und überlässt es der gesonderten Untersuchung.

    Hebbare Singularitäten

    ${sin x}/{x}$ ist bei 0 nicht definiert (ergibt 0/0), aber entwickelt man den Zähler, $sin x/x = (x − {x^3}/{6} + …)/x = 1 − {x^2}/{6} + …$, sieht man, dass sie gegen 1 strebt. Gibt man ihr bei 0 diesen Wert, ist die Funktion differenzierbar und hat ein Taylor-Polynom.

    Grenzwerte mit Taylor

    Bei einem Grenzwert 0/0 ersetzt man Zähler und Nenner durch ihre Entwicklungen und vergleicht den ersten nicht verschwindenden Term jeder: Beginnen sie mit derselben Potenz, ist der Grenzwert der Quotient ihrer Koeffizienten; beginnt der Zähler höher, ist er 0; und beginnt der Nenner höher, geht er gegen ±∞ (oder existiert nicht, wenn die einseitigen Grenzwerte verschiedene Vorzeichen haben). Zum Beispiel,

    $lím_{x → 0} {sen x − x}/{x^3} = lím_{x → 0} {−{x^3}/{6} + …}/{x^3} = −{1}/{6}$

    Einen Grenzwert im Unendlichen führt man mit der Substitution $t = {1}/{x}$ auf 0 zurück (schreibe inf oder -inf an die Stelle): $lim_{x → ∞} x sin({1}/{x}) = lim_{t → 0} {sin t}/{t} = 1$. Und eine Potenz mit x im Exponenten schreibt man als $f^g = e^{g · ln f}$ und berechnet den Grenzwert des Exponenten: $lim_{x → ∞} (1 + {1}/{x})^x = e^{lim x · ln(1 + 1/x)} = e^1 = e$.

    Häufige Fragen

    Wie berechnet man das Taylor-Polynom?

    P(x) = Σ f⁽ⁿ⁾(a)/n!·(x − a)ⁿ, und Maclaurin, wenn a = 0. Zum Beispiel eˣ ≈ 1 + x + x²/2 + x³/6, sin x ≈ x − x³/6 und cos x ≈ 1 − x²/2 + x⁴/24. Mit Grad 3 ist e^0,1 ≈ 1,105167 (der wahre Wert ist 1,105171).

    Wie schätzt man den Fehler ab?

    Mit dem Lagrange-Restglied, R_n = f⁽ⁿ⁺¹⁾(c)/(n + 1)!·(x − a)ⁿ⁺¹ für ein c zwischen a und x. Mit Grad 2 für e^0,1: |R| ≤ e^0,1/3! · 0,1³ ≈ 1,8·10⁻⁴.
