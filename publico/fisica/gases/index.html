Gases ideales

Aplica la ecuación de estado PV = nRT, encadena transformaciones isotermas, isobaras, isocoras y adiabáticas para obtener el trabajo, el calor y la energía interna de cada tramo y el rendimiento de un ciclo, y calcula las velocidades de las moléculas con la teoría cinética.

Desarrollo

    Ecuación de estado

    $P V = n R T$,   $R = 8,314 "J/(mol·K)" = 0,082 "atm·L/(mol·K)"$

    La temperatura siempre en kelvin (T = t + 273,15). En condiciones normales (1 atm y 0 °C) un mol ocupa 22,4 L. La densidad de un gas es ρ = PM/(RT).

    Primer principio

    $ΔU = Q − W$,   $ΔU = n C_v ΔT$,   $C_p − C_v = R$,   $γ = C_p/C_v$

    W es el trabajo que hace el gas (positivo si se expande) y Q el calor que recibe. Un gas monoatómico tiene Cv = 3R/2 y uno diatómico Cv = 5R/2.

    Transformaciones

    Isoterma (T constante): ΔU = 0 y Q = W = nRT ln(V2/V1). Isobara (P constante): W = PΔV y Q = nCpΔT. Isocora (V constante): W = 0 y Q = nCvΔT. Adiabática (Q = 0): PVγ = cte, TVγ−1 = cte y W = (P1V1 − P2V2)/(γ − 1).

    Ciclos

    En un ciclo el gas vuelve al estado inicial, así que ΔU = 0 y Wneto = Qneto, que es el área encerrada en el diagrama P-V. El rendimiento es η = W/Qabs, y nunca supera el de un ciclo de Carnot entre las mismas temperaturas, η = 1 − Tf/Tc.

    Teoría cinética

    $v_cm = √({3RT}/M)$,   $⟨E_c⟩ = 3/2 k T$

    Las velocidades de las moléculas siguen la distribución de Maxwell: la más probable es √(2RT/M) y la media √(8RT/(πM)). La energía cinética media solo depende de la temperatura.
