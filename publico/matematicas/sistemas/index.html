Sistemas de ecuaciones lineales

Escribe los coeficientes y los términos independientes. Verás si el sistema es compatible determinado, indeterminado o incompatible (Rouché-Frobenius) y su solución por Gauss, Gauss-Jordan, Cramer, la matriz inversa, reducción, igualación o sustitución, en paramétricas si tiene infinitas. Admite fracciones exactas y números complejos.

Resultado

Desarrollo

    Teorema de Rouché-Frobenius

    Un sistema de m ecuaciones con n incógnitas se escribe A x = b, con A la matriz de coeficientes y A* = [A | b] la matriz ampliada. Comparando sus rangos se sabe cuántas soluciones tiene sin resolverlo:

    • rang(A) = rang(A*) = n: compatible determinado, una única solución.
    • rang(A) = rang(A*) < n: compatible indeterminado, infinitas soluciones que dependen de n − rang(A) parámetros.
    • rang(A) < rang(A*): incompatible, sin solución. Al escalonar aparece una fila 0 = k con k ≠ 0.

    Un sistema homogéneo (b = 0) siempre es compatible, porque x = 0 es solución. Tiene más soluciones si y solo si rang(A) < n.

    Métodos

    Gauss: se escalona la matriz ampliada y se despejan las incógnitas desde la última ecuación hacia arriba. Gauss-Jordan: se sigue reduciendo hasta que cada pivote vale 1 y es el único de su columna, y la solución se lee directamente. Cramer: si A es cuadrada y |A| ≠ 0, cada incógnita es un cociente de determinantes. Matriz inversa: en el mismo caso, x = A−1 b.

    $x_i = {|A_i|}/{|A|}$,   $A_i$ = A con la columna i cambiada por b

    Reducción, igualación y sustitución

    Son los métodos de siempre para sistemas de 2 o 3 ecuaciones. Reducción: se multiplican dos ecuaciones por los números adecuados y se restan para que desaparezca una incógnita. Igualación: se despeja la misma incógnita en todas las ecuaciones y se igualan las expresiones. Sustitución: se despeja una incógnita en una ecuación y se sustituye en las demás. Cada paso deja un sistema con una incógnita menos; al final se vuelve hacia atrás para calcular las que se apartaron.

    Con números complejos

    Todo lo anterior vale igual con coeficientes complejos, como al plantear las mallas de un circuito de alterna con impedancias Z = R + jX: los pivotes se dividen como números complejos y el resultado sale en forma binómica.
