    Las cuatro formas de un complejo

    Un número complejo z = a + bi tiene parte real a y parte imaginaria b, con $i^2 = −1$. Se dibuja como el punto (a, b) del plano complejo (su afijo) o como la flecha desde el origen hasta él. Esa flecha tiene una longitud, el módulo r, y forma un ángulo con el eje real, el argumento θ:

    $r = |z| = √(a^2 + b^2)$,   $tg θ = b/a$

    • Binómica: $z = a + bi$
    • Polar: $z = r_θ$ (también se escribe r∠θ)
    • Trigonométrica: $z = r(cos θ + i sen θ)$, con $a = r cos θ$ y $b = r sen θ$
    • Exponencial: $z = r e^{iθ}$, por la fórmula de Euler $e^{iθ} = cos θ + i sen θ$, con θ en radianes

    Cuidado con el cuadrante. La calculadora da arctg(b/a) entre −90° y 90°, así que si a < 0 (segundo o tercer cuadrante) hay que sumar o restar 180°. Por ejemplo, −1 + i y 1 − i dan los dos arctg(−1) = −45°, pero el argumento de −1 + i es 135°.

    Operaciones

    Para sumar y restar se usa la forma binómica: se suman las partes reales y las imaginarias (es la regla del paralelogramo). Para multiplicar y dividir es más cómoda la polar:

    $r_α · s_β = (r s)_{α + β}$,   $r_α / s_β = (r/s)_{α − β}$

    En binómica, el producto se hace como el de dos binomios usando $i^2 = −1$, y el cociente multiplicando arriba y abajo por el conjugado del denominador, $z̄ = a − bi$, porque $z z̄ = a^2 + b^2$ es real.

    Potencias y raíces

    La fórmula de De Moivre eleva el módulo y multiplica el argumento:

    $(r_θ)^n = (r^n)_{nθ}$

    Un complejo distinto de cero tiene exactamente n raíces n-ésimas, todas con el mismo módulo y repartidas cada 360°/n, en los vértices de un polígono regular:

    $(r_θ)^{1/n} = (r^{1/n})_{(θ + 360° k)/n}$,   $k = 0, 1, …, n − 1$

    Ecuaciones de segundo grado

    Con los complejos, toda ecuación $a z^2 + b z + c = 0$ tiene dos soluciones, $z = {−b ± √Δ}/{2a}$. Si los coeficientes son reales y $Δ = b^2 − 4ac < 0$, las soluciones son complejas conjugadas, porque $√Δ = i √(−Δ)$.

    Logaritmo, exponencial y potencias complejas

    La exponencial de z = a + bi es ez = ea(cos b + i sen b): tiene módulo ea y argumento b, y se repite cada 2πi. Por eso el logaritmo tiene infinitos valores, ln z = ln|z| + i(θ + 2kπ); el principal es el de −π < θ ≤ π. Con él se definen las potencias de exponente complejo, zw = ew ln z: por ejemplo, ii = e−π/2 es un número real.

    Ecuaciones polinómicas y regiones

    Una ecuación polinómica de grado n tiene exactamente n soluciones complejas, contando las repetidas (teorema fundamental del álgebra). Las racionales se buscan con Ruffini entre los divisores del término independiente, y si los coeficientes son reales, las complejas van por parejas de conjugadas. En el plano, |z − a| = r es la circunferencia de centro a y radio r, |z − a| < r su interior, Re z > c un semiplano y |z − a| = |z − b| la mediatriz del segmento que une a y b.
