Series de Taylor

Calcula el polinomio de Taylor (o de Maclaurin) de una función en un punto con sus derivadas y coeficientes, úsalo para aproximar un valor y acota el error con el resto de Lagrange. La gráfica muestra cómo cada grado se acerca más a la función.

Datos

Escribe la función con x: e^x, sen x, cos(2x), ln(1+x), √x, arctg x, 1/(1−x), x^3 − 2x… El punto puede llevar π: π/6. En «Límite con Taylor» escribe un cociente: (sen x − x)/x^3.

    El polinomio de Taylor

    Cerca de un punto a, una función derivable se parece a un polinomio que tiene en a el mismo valor y las mismas derivadas que ella. El de grado n es el polinomio de Taylor:

    $P_n(x) = f(a) + f′(a) (x − a) + {f″(a)}/{2!} (x − a)^2 + … + {f^{(n)}(a)}/{n!} (x − a)^n$

    El coeficiente de $(x − a)^k$ es $c_k = {f^{(k)}(a)}/{k!}$. El de grado 1 es la recta tangente, y cada grado más corrige la curvatura un poco mejor. Cuando a = 0 se llama polinomio de Maclaurin.

    El error: resto de Lagrange

    Al cambiar f(x) por $P_n(x)$ se comete un error, el resto $R_n(x) = f(x) − P_n(x)$. Si f tiene derivada n + 1 entre a y x, hay un ξ entre los dos con

    $R_n(x) = {f^{(n+1)}(ξ)}/{(n+1)!} (x − a)^{n+1}$

    No se sabe cuánto vale ξ, pero si $|f^{(n+1)}| ≤ M$ en ese intervalo, el error es como mucho $M |x − a|^{n+1}/(n+1)!$. Para que el error sea menor que una cantidad dada se busca el n más pequeño que lo cumple.

    Desarrollos conocidos de Maclaurin

    • $e^x = 1 + x + {x^2}/{2!} + {x^3}/{3!} + … = Σ_{k=0}^{∞} {x^k}/{k!}$, para todo x
    • $sen x = x − {x^3}/{3!} + {x^5}/{5!} − … = Σ_{k=0}^{∞} {(−1)^k x^{2k+1}}/{(2k+1)!}$, para todo x
    • $cos x = 1 − {x^2}/{2!} + {x^4}/{4!} − … = Σ_{k=0}^{∞} {(−1)^k x^{2k}}/{(2k)!}$, para todo x
    • $ln (1 + x) = x − {x^2}/{2} + {x^3}/{3} − … = Σ_{k=1}^{∞} {(−1)^{k+1} x^k}/{k}$, para −1 < x ≤ 1
    • ${1}/{1 − x} = 1 + x + x^2 + x^3 + … = Σ_{k=0}^{∞} x^k$, para |x| < 1
    • $arctg x = x − {x^3}/{3} + {x^5}/{5} − … = Σ_{k=0}^{∞} {(−1)^k x^{2k+1}}/{2k+1}$, para |x| ≤ 1
    • $(1 + x)^α = 1 + α x + {α (α − 1)}/{2!} x^2 + … = Σ_{k=0}^{∞} binom(α, k) x^k$, para |x| < 1

    Con ellos se sacan otros sin derivar: cambiando x por $−x^2$ en el de $e^x$ sale $e^{−x^2} = 1 − x^2 + {x^4}/{2} − …$, y multiplicando por x el de sen x sale el de x sen x.

    Radio de convergencia

    La serie de Taylor $Σ c_k (x − a)^k$ converge para $|x − a| < R$ y no converge para $|x − a| > R$. El radio se saca con el criterio del cociente, $R = lím_{k → ∞} {|c_k|}/{|c_{k+1}|}$, o con el de la raíz, ${1}/{R} = lím sup |c_k|^{1/k}$, y es la distancia de a al punto más cercano, también complejo, donde f deja de estar definida: para ${1}/{1 + x^2}$ en a = 0 es R = 1, por los puntos ±i, aunque en los reales la función no tiene problemas.

    Fuera de su intervalo de convergencia la serie no se acerca a la función por mucho que suba el grado: pruébalo con ln(1 + x) y x₀ = 1,5. Y sumando estas series con x = iθ sale la fórmula de Euler, $e^{iθ} = cos θ + i sen θ$, que se usa en Números complejos.

    La calculadora estima R con 80 coeficientes, busca en el plano complejo la singularidad que lo fija y estudia los dos extremos, $x = a ± R$, donde cada serie va por su cuenta: la de ln(1 + x) converge en x = 1 (serie armónica alternada) y diverge en x = −1 (serie armónica), así que su intervalo de convergencia es $(−1, 1]$. Cuando en un extremo los signos no siguen un patrón, lo dice y lo deja para estudiarlo aparte.

    Singularidades evitables

    ${sen x}/{x}$ no está definida en 0 (sale 0/0), pero desarrollando el numerador, $sen x/x = (x − {x^3}/{6} + …)/x = 1 − {x^2}/{6} + …$, se ve que tiende a 1. Dándole ese valor en 0 la función queda derivable y tiene polinomio de Taylor.

    Límites con Taylor

    Para un límite 0/0 se cambian el numerador y el denominador por sus desarrollos y se compara el primer término que no se anula en cada uno: si empiezan con la misma potencia, el límite es el cociente de sus coeficientes; si el numerador empieza más alto, es 0; y si empieza más alto el denominador, va a ±∞ (o no existe si los laterales tienen distinto signo). Por ejemplo,

    $lím_{x → 0} {sen x − x}/{x^3} = lím_{x → 0} {−{x^3}/{6} + …}/{x^3} = −{1}/{6}$

    Un límite en el infinito se lleva a 0 con el cambio $t = {1}/{x}$ (escribe inf o -inf en el punto): $lím_{x → ∞} x sen({1}/{x}) = lím_{t → 0} {sen t}/{t} = 1$. Y una potencia con la x en el exponente se escribe como $f^g = e^{g · ln f}$ y se calcula el límite del exponente: $lím_{x → ∞} (1 + {1}/{x})^x = e^{lím x · ln(1 + 1/x)} = e^1 = e$.

    Preguntas frecuentes

    ¿Cómo se calcula el polinomio de Taylor?
