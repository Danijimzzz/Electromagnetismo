Multiplicateurs de Lagrange

Trouve les maxima et minima d’une fonction de deux ou trois variables sous une contrainte g = c : pose ∇f = λ∇g, trouve les points critiques, calcule λ et indique si chacun est un maximum, un minimum ou un point selle, avec les lignes de niveau.

Données

Variables x et y (et z si tu l’utilises) : x^2 + y^2, x y, 2x + 3y, e^(x y), x^2 y z… La contrainte est g(x, y) = c ; écris c à droite. Les points sont cherchés numériquement et les valeurs exactes sont reconnues (√2/2, 1/3…).

    L’idée

    Pour optimiser $f(x, y)$ sur la courbe $g(x, y) = c$, en un extremum la ligne de niveau de $f$ est tangente à la contrainte : les gradients sont parallèles.

    $∇f = λ ∇g, \quad g(x, y) = c$

    Ce sont trois équations (quatre avec trois variables) d’inconnues $x$, $y$, $λ$. Le nombre $λ$ est le multiplicateur et mesure de combien change l’optimum si $c$ change : $λ = d f^{*}/d c$.

    Maximum, minimum ou selle

    Avec le lagrangien $L = f − λ g$, en chaque point critique on étudie la hessienne de $L$ uniquement dans les directions tangentes à la contrainte. À deux variables, avec $t = (−g_y, g_x)$, le signe de $q = t^T H_L t$ tranche : $q > 0$ minimum, $q < 0$ maximum (équivaut au déterminant de la hessienne bordée, au signe près). À trois variables on regarde la hessienne sur le plan tangent : deux valeurs propres positives, minimum ; négatives, maximum ; de signes différents, selle.

    Les points critiques ne sont que des candidats : pour dire lequel est le maximum absolu on compare les valeurs de $f$, et si la contrainte n’est pas fermée et bornée il se peut qu’il n’y ait ni maximum ni minimum.

    Questions fréquentes

    Comment utilise-t-on les multiplicateurs de Lagrange ?

    Pour optimiser f sous la contrainte g = c, on résout ∇f = λ∇g avec g = c. Pour f = x² + y² avec x + y = 2 : 2x = λ, 2y = λ et x + y = 2 donnent x = y = 1, λ = 2 et f = 2, qui est le minimum.

    Comment savoir si le point est un maximum ou un minimum ?

    On regarde la hessienne de L = f − λg dans la direction tangente à la contrainte : q > 0 correspond à un minimum et q < 0 à un maximum (à deux variables, le signe contraire à celui de la hessienne bordée). Pour x y avec 2x + 2y = 20 on obtient x = y = 5, f = 25 et c’est un maximum.
