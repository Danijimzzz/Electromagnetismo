    Moindres carrés ordinaires

    Le modèle de régression simple est $Y_i = β_0 + β_1 X_i + u_i$, où $u_i$ est la perturbation. Les estimateurs des moindres carrés sont ceux qui minimisent la somme des carrés des résidus :

    $β̂_1 = {∑ (x_i − x̄)(y_i − ȳ)}/{∑ (x_i − x̄)^2}$, $β̂_0 = ȳ − β̂_1 x̄$

    Le $R^2$ mesure la part de la variation de Y qu’explique le modèle, et le test $t = β̂_1/s(β̂_1)$, à $n − 2$ degrés de liberté, indique si l’effet de X est significatif.

    Comment lire chaque forme

    Dans le modèle linéaire, $β_1$ est l’effet marginal : ce dont varie Y quand X augmente d’une unité. C’est ce qu’on utilise, par exemple, pour la propension marginale à consommer dans $C = C_0 + c Y_d$.

    Dans le modèle double logarithmique, $ln Y = β_0 + β_1 ln X$, $β_1$ est l’élasticité : la variation en pourcentage de Y quand X augmente de 1 %. C’est la forme habituelle pour estimer des élasticités de la demande ou des courbes d’Engel.

    Dans le modèle semi-logarithmique, $ln Y = β_0 + β_1 X$, Y croît à un rythme constant : chaque unité de X la multiplie par $e^{β_1}$. Avec X en années, $e^{β_1} − 1$ est le taux de croissance annuel.

    Précautions

    Que deux variables soient liées ne signifie pas que l’une cause l’autre : une troisième peut se cacher derrière, comme le temps dans deux séries qui croissent ensemble. De plus, prévoir en dehors de la plage des données (extrapoler) est risqué, et dans les séries temporelles les résidus sont souvent corrélés, ce qui rend les erreurs types trop petites.

    Questions fréquentes

    Comment interprète-t-on une droite de régression en économie ?

    La pente est l’effet marginal. Dans la fonction de consommation C = 200 + 0,8Y, chaque euro de revenu en plus augmente la consommation de 0,8 € (propension marginale à consommer) ; le R² indique quelle part de la variation le revenu explique.

    Et un ajustement logarithmique ou exponentiel ?

    Dans ln Q = a + b ln P, b est l’élasticité constante : avec b = −1,5, une hausse de 1 % du prix réduit la quantité de 1,5 %. Dans ln y = a + bt, b est le taux de croissance.
