    Qué es una renta

    Una renta es una serie de pagos (términos) a intervalos regulares: el alquiler, las cuotas de un préstamo, una pensión o lo que se ahorra cada mes. Para sumarlos hay que llevarlos todos al mismo momento: al origen (valor actual) o al final (valor final).

    Renta pospagable

    Los términos se pagan al final de cada periodo. Con n términos de cuantía C y un tipo i por periodo:

    $V_0 = C · a_{n¬i} = C {1 − (1 + i)^{−n}}/i$, $V_n = C · s_{n¬i} = C {(1 + i)^n − 1}/i$

    Prepagable, diferida y perpetua

    Si se paga al principio de cada periodo (prepagable), cada término gana un periodo más de interés y todo se multiplica por $(1 + i)$. Si la renta empieza d periodos más tarde (diferida), su valor actual se descuenta además por $(1 + i)^{−d}$. Si no se acaba nunca (perpetua), $(1 + i)^{−n} → 0$ y

    $V_0 = C/i$

    El tipo de cada periodo

    Si los términos son mensuales, el tipo tiene que ser mensual. A partir del tipo efectivo anual (la TAE), el equivalente de cada periodo es $i_m = (1 + i)^{1/m} − 1$, con m = 12 para meses, 4 para trimestres y 2 para semestres.
